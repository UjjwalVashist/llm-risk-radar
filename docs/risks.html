The ten risks

The OWASP Top 10 for LLM Applications (2025) in plain words, with the keywords this site uses to sort headlines.

LLM01 Prompt Injection

Someone hides instructions in text, a web page or a file, and the AI follows them instead of its real task.

Keywords: prompt injection, indirect prompt, jailbreak, jailbreaking, prompt-injection, injected instructions, injection attack, zero-click, hidden instructions

LLM02 Sensitive Information Disclosure

The AI reveals private or confidential data: from its training, its context, or other users.

Keywords: data leak, data leakage, leaks data, exfiltration, exfiltrate, data exposure, sensitive data, sensitive information, privacy, datenleck, datenabfluss, datenschutz, personal data, personenbezogene, confidential

LLM03 Supply Chain

A risk arrives through something the AI system depends on: a model, a plugin, a library or a dataset.

Keywords: supply chain, lieferkette, malicious package, malicious model, hugging face, pypi, npm package, plugin, extension, mcp server, third-party, dependency, backdoored

LLM04 Data and Model Poisoning

Someone manipulates the training data or the model itself, so the AI learns something false or harmful.

Keywords: poisoning, poisoned, data poisoning, model poisoning, backdoor, training data, trainingsdaten, fine-tuning, sleeper agent, manipulated model, tampering, manipulation

LLM05 Improper Output Handling

Software trusts what the AI writes and runs it or shows it without checking: code, links, commands.

Keywords: remote code execution, rce, code execution, xss, cross-site scripting, sql injection, command injection, output handling, unsanitized, markdown image, arbitrary code, codeausführung, run code, execute code, run arbitrary, schadcode

LLM06 Excessive Agency

An AI agent has more permissions or tools than it needs, so a mistake or an attack does real damage.

Keywords: agent, agents, agentic, ki-agent, ki-agenten, autonomous, excessive agency, tool use, tool call, computer use, privilege, permissions, berechtigungen, mcp

LLM07 System Prompt Leakage

The hidden instructions of an AI product leak, sometimes together with keys or internal details.

Keywords: system prompt, systemprompt, prompt leak, prompt leakage, leaked prompt, prompt extraction, api key, api keys, hardcoded, secrets, credentials, zugangsdaten

LLM08 Vector and Embedding Weaknesses

Weak points in the document search behind an AI assistant (RAG): wrong or planted documents get pulled in.

Keywords: rag, retrieval-augmented, retrieval augmented, vector database, vector store, embedding, embeddings, knowledge base, vektordatenbank

LLM09 Misinformation

The AI states false things convincingly, or is used to produce fakes at scale.

Keywords: hallucination, hallucinations, halluzination, misinformation, disinformation, desinformation, deepfake, deepfakes, fake news, fabricated, falschinformation, voice cloning, impersonation, fake, phishing, scam, betrug

LLM10 Unbounded Consumption

The AI is made to use huge amounts of computing power or money, or its model is copied through mass queries.

Keywords: denial of service, denial-of-service, dos attack, resource exhaustion, model extraction, model theft, denial of wallet, rate limit, token cost, unbounded consumption, distillation attack
