KI sicher nutzen

Acht Regeln für den Alltag mit ChatGPT, Copilot, Claude und anderen KI-Assistenten bei der Arbeit.

1Vertrauliche Daten bleiben draußen

✓ Richtig: Nutzen Sie erfundene oder anonymisierte Beispiele, wenn Sie Hilfe brauchen.

✕ Falsch: Kundendaten, persönliche Daten, Verträge oder unveröffentlichte Zahlen in ein öffentliches KI-Tool kopieren.

Schützt vor: LLM02 Sensitive Information Disclosure

2Nur freigegebene Tools nutzen

✓ Richtig: Arbeiten Sie mit den KI-Tools, Plugins und Erweiterungen, die Ihre Firma freigegeben hat.

✕ Falsch: Ein unbekanntes KI-Plugin oder eine Browser-Erweiterung installieren, weil es praktisch aussieht.

Schützt vor: LLM03 Supply Chain

3Erst prüfen, dann vertrauen

✓ Richtig: Prüfen Sie Fakten, Zahlen und Quellen. KI klingt oft sicher und liegt trotzdem falsch.

✕ Falsch: Eine KI-Antwort ungeprüft in einen Bericht, eine Kunden-E-Mail oder eine Entscheidung übernehmen.

Schützt vor: LLM09 Misinformation

4Texte können die KI angreifen

✓ Richtig: Seien Sie vorsichtig, wenn ein Assistent Webseiten, E-Mails oder fremde Dateien zusammenfasst.

✕ Falsch: Glauben, dass ein Dokument harmlos ist. Versteckte Anweisungen darin können die KI steuern.

Schützt vor: LLM01 Prompt Injection

5Code, Befehle und Links prüfen

✓ Richtig: Lesen und testen Sie Code und Befehle von der KI, bevor Sie sie ausführen.

✕ Falsch: Einen Befehl ausführen oder einen Link anklicken, nur weil die KI es vorschlägt.

Schützt vor: LLM05 Improper Output Handling

6KI-Agenten: wenig Rechte

✓ Richtig: Ein Agent bekommt nur die Rechte, die er für die Aufgabe braucht. Wichtige Schritte bestätigen Sie selbst.

✕ Falsch: Einem Agenten „zur Sicherheit“ vollen Zugriff auf Postfach, Dateien oder Systeme geben.

Schützt vor: LLM06 Excessive Agency

7Keine Geheimnisse im Prompt

✓ Richtig: Passwörter, API-Keys und Tokens gehören in den Passwort-Manager.

✕ Falsch: Geheimnisse in einen Prompt, einen Chat oder die Anweisungen eines eigenen Assistenten schreiben.

Schützt vor: LLM07 System Prompt Leakage

8Schnell melden

✓ Richtig: Informieren Sie Ihr Security-Team, wenn Daten im falschen Tool gelandet sind oder eine KI sich seltsam verhält.

✕ Falsch: Aus Scham schweigen. Eine schnelle Meldung begrenzt den Schaden.

Schützt vor: Alle Risiken

Unsicher? Fragen Sie zuerst Ihr Security-Team. Grundlage: OWASP Top 10 for LLM Applications (2025).
