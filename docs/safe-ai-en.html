Using AI safely

Eight everyday rules for ChatGPT, Copilot, Claude and other AI assistants at work.

1Keep confidential data out

✓ Do: Use made-up or anonymised examples when you ask for help.

✕ Don't: Paste customer data, personal data, contracts or unpublished figures into a public AI tool.

Protects against: LLM02 Sensitive Information Disclosure

2Use approved tools only

✓ Do: Work with the AI tools, plugins and extensions your company has approved.

✕ Don't: Install an unknown AI plugin or browser extension because it looks useful.

Protects against: LLM03 Supply Chain

3Check before you trust

✓ Do: Verify facts, figures and sources. AI can sound certain and still be wrong.

✕ Don't: Copy an AI answer into a report, an email to a customer or a decision without checking it.

Protects against: LLM09 Misinformation

4Text the AI reads can attack it

✓ Do: Be careful when an assistant summarises web pages, emails or files from outside.

✕ Don't: Assume a document is harmless. Hidden instructions in it can steer the AI.

Protects against: LLM01 Prompt Injection

5Review code, commands and links

✓ Do: Read AI-written code and commands, and test them, before you run them.

✕ Don't: Run a command or click a link only because the AI suggested it.

Protects against: LLM05 Improper Output Handling

6Give AI agents small permissions

✓ Do: Let an agent do only what the task needs, and confirm important steps yourself.

✕ Don't: Give an agent full access to your mailbox, files or systems “to be safe”.

Protects against: LLM06 Excessive Agency

7No secrets in prompts

✓ Do: Keep passwords, API keys and access tokens in the password manager.

✕ Don't: Write secrets into a prompt, a chat or the instructions of a custom assistant.

Protects against: LLM07 System Prompt Leakage

8Report it, quickly

✓ Do: Tell your security team if data ended up in the wrong tool or an AI behaved strangely.

✕ Don't: Stay silent out of embarrassment. Fast reports limit the damage.

Protects against: All risks

Not sure? Ask your security team before you act. Based on the OWASP Top 10 for LLM Applications (2025).
